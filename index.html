GOOD TO KNOW

Frequently asked questions

Can I download from TikTok, Instagram, Facebook or YouTube?

This starter detects these links but does not extract media from their pages. Use each platform's official download/export feature or connect an authorized API integration that permits the requested use.

Does it remove watermarks?

No. It does not remove or bypass watermarks, DRM, privacy settings, login requirements, or other platform protections.

Which links can I download?

Public direct links to supported video or audio files, provided you own the content or have permission to download it.

Is there a file-size limit?

The default server limit is 150 MB. The owner can adjust it using the MAX_DOWNLOAD_MB environment setting.
